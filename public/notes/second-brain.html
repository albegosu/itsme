Second Brain

Save UI inspiration from any app. A vision model curates it into a private wiki and turns your taste into a DESIGN.md your coding agent builds from.

Overview

Product Python Open Source

I collect references as I scroll: UI demos, product behaviours worth copying, tools to try. In a bookmarks folder they rot. Second Brain turns every share into a Markdown wiki in my own repository, and Claude checks that wiki before it designs or builds anything.

The repository is the engine. The wiki lives in a separate private repository, written by a worker and read by the agent.

The loop

  1. Share a post from X, Instagram or LinkedIn, any page, a screenshot or a photo — from the share sheet on iPhone or Mac, an installable capture page on Android and desktop, or the command line.
  2. Queue. A cloud inbox accepts it instantly, even with every computer off.
  3. Understand. A worker on GitHub Actions downloads the media, samples frames across the video, measures the palette from pixels and asks a vision model for patterns, style and a topic.
  4. File. A source note keeps the extraction verbatim, the topic page absorbs what's new and cites it, and the change is committed to the wiki.
  5. Use. The second-brain skill reads the index, opens only the relevant topics and cites them while Claude builds. Other agents read it over a read-only MCP server.

What sets it apart

It sees how interfaces move

Frames are sampled across the whole video and each interaction is described as a trigger, numbered steps and animated properties. Other tools index what a video says, not what the screen does.

It measures instead of guessing

The palette comes from pixels, traits from a closed vocabulary. Durations and easing curves are left out on purpose: still frames can't measure them.

A wiki you own, built for an agent

Topic pages synthesise several captures with inline citations. Code writes the structure and the model writes the prose, so a bad answer can spoil a paragraph but never the navigation.

Your own DESIGN.md

Your taste across every capture, or any single saved style, becomes a lint-clean DESIGN.md with tokens derived by code. getdesign.md gives you Stripe's; this gives you yours.

Outputs

wiki/ one page per topic and one source note per capture, kept tidy by a weekly lint pass.

taste.md the choices I keep making, as a default look and motion.

DESIGN.md that taste as design tokens, with a dark or light twin when captures split.

AGENTS.md the ideas from what I read, as rules a coding agent follows.

stack.md the tools I saved, by job: used, to try or stale.

Quick start

Needs gh logged in and a model key: a free Ollama key by default, or OpenAI, Anthropic, Gemini or OpenRouter.

git clone https://github.com/albegosu/second-brain ~/Developer/second-brain cd ~/Developer/second-brain bin/setup

bin/setup creates the private wiki and inbox repositories, wires them together and prints how to connect the iPhone Shortcut or the capture page.
